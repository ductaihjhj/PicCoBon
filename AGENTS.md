# Project Instructions

## Frontend Design

When implementing or modifying frontend UI:

- Read `.agent/skills/frontend-design/SKILL.md`.
- Follow the project's existing design system.
- Maintain consistent spacing, typography and colors.
- Ensure responsive layouts.
- Reuse existing components.
- Avoid unnecessary dependencies.

## Project Safety

- Preserve existing business logic.
- Do not modify APIs or database schemas without approval.
- Avoid unrelated refactoring.
- Run available lint, typecheck and build checks.
- Test affected user flows when possible.
- Do not claim tests passed unless executed.

## 1. Nguyên Tắc Bất Biến (Core Data Integrity Rules)

1. **Single Source of Truth**: Mọi trạng thái sân, khung giờ bận, báo giá, tồn kho Pro Shop, trạng thái thanh toán và số liệu doanh thu trên UI đều bắt nguồn từ SQL Server thông qua các API của [`ApiDbController.cs`](file:///e:/pickleball/Controllers/ApiDbController.cs).
2. **Zero False Availability (`UI-A01`)**: Khi `/api/db/state` chưa phản hồi (`initial` / `loading`) hoặc gặp lỗi (`error` / `offline`), UI giữ `HAS_SERVER_STATE = false`, không hiển thị số sân trống giả từ `DEFAULT_COURTS`, và khóa nút gửi form đặt sân.
3. **Strict Server Quote Binding (`UI-A02`)**: Mọi thay đổi trên `{courtId, date, time, duration}` lập tức hủy báo giá cũ (`latestServerQuote = null`), hủy request đang bay bằng `AbortController`, và yêu cầu báo giá mới từ `/api/bookings/quote` trước khi cho phép bấm **"Xác Nhận Đặt Sân"**.
4. **Ledger-Driven Financials (`UI-A03`, `UI-B04`)**:
   - Doanh thu thực thu chỉ được tổng hợp từ bảng `tb_PaymentTransaction` (`Status = 'completed'`), trừ đi các bút toán `TransactionType = 'refund'`.
   - Vé điện tử QR (`SpikeTicket`) hiển thị tách biệt 3 trường: **Tổng phải thanh toán (`amountDue`)**, **Đã thanh toán (`paidAmount`)**, và **Còn lại (`remainingDue = Math.Max(0, amountDue - paidAmount)`)**.

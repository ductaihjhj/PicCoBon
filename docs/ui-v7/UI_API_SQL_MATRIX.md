# Ma Trận Liên Kết Dữ Liệu UI ↔ API ↔ SQL Server (`UI_API_SQL_MATRIX.md`)

Toàn bộ dữ liệu hiển thị trên giao diện V7 tuân thủ nguyên tắc **Server-Authoritative (Máy chủ và SQL Server là nguồn sự thật duy nhất)**. Không sử dụng dữ liệu giả lập khi API lỗi hoặc chưa tải xong.

---

| Màn hình / Thành phần UI | Endpoint API / MVC Action | Service xử lý | Bảng SQL Server (`PickleballClub`) | Cơ chế đồng bộ & Chống lỗi |
|---|---|---|---|---|
| **Trạng thái toàn cục CLB (`shared.js`)** | `GET /api/db/state` | `ApiDbController.GetState`, `ClubSettingsService`, `BookingService`, `ProductImageService` | `tb_Court`, `tb_Booking`, `tb_CourtLock`, `tb_Product`, `tb_ProductCategory`, `tb_Order`, `tb_PaymentTransaction`, `tb_CmsConfig` | Hỗ trợ `ETag` (`If-None-Match` → `304 Not Modified`), tự động làm mới ETag khi bất kỳ trường sân, đơn đặt, sản phẩm (`p.Image`), khóa sân hoặc CMS thay đổi. Khi mất mạng/lỗi 500 hiển thị banner trạng thái thật (`#globalSyncStatusBanner`). |
| **Báo giá đặt sân (`/Booking`)** | `GET /api/bookings/quote` | `PricingService.CalculateQuoteAsync` | `tb_Court`, `tb_CmsConfig`, `tb_Account` | Tính giá bậc thang theo từng khung 30 phút + phụ thu VIP + chiết khấu hạng thẻ hội viên kèm `PricingVersion`. Nếu khách đổi sân/ngày/giờ, báo giá cũ bị vô hiệu hóa ngay lập tức. |
| **Tạo đơn đặt sân (`/Booking`)** | `POST /api/bookings` | `BookingService.CreateBookingAsync` | `tb_Booking`, `tb_CourtLock`, `tb_AuditLog` | Khóa giao dịch `Serializable` chống đặt trùng sân cùng khung giờ (`409 Conflict`), kiểm tra `Idempotency-Key`, cấp `AccessToken` (`bk_...`) và `CheckInToken` ký số HMAC-SHA256 (`SPK1...`). |
| **Tra cứu vé & Tải mã QR (`/Lookup`, `/Booking`)** | `GET /api/bookings/lookup`, `GET /api/bookings/{code}/qr.png`, `GET /api/bookings/{code}/qr.svg` | `ApiDbController`, `QrTokenService` | `tb_Booking`, `tb_Court` | Xác thực quyền sở hữu vé (chủ tài khoản, Staff/Admin hoặc khách có `bk_...` hợp lệ). Sinh ảnh QR PNG/SVG thật bằng `QRCoder` với ECC Level M và vùng trắng chuẩn. |
| **Soát vé QR (`/Checkin`)** | `POST /api/admin/checkin`, `POST /api/admin/checkin/qr-image` | `BookingService.CheckInBookingAsync`, `QrTokenService`, `ZXing.ImageSharp` | `tb_Booking`, `tb_AuditLog` | Giải mã ảnh QR bằng `ZXing` hoặc xác thực chữ ký `SPK1...`; từ chối vé `pending` (`409`), vé đã hủy/hết hạn hoặc vé đã check-in trước đó (chống replay). |
| **Đặt hàng Pro Shop (`/Product`)** | `POST /api/orders` | `OrderService.CreateOrderAsync` | `tb_Order`, `tb_OrderDetail`, `tb_Product`, `tb_Booking`, `tb_InventoryMovement` | Kiểm tra `Idempotency-Key`, trừ tồn kho nguyên tử trong `tb_Product` (`UnitInStock`, `Quantity`), ghi nhận `tb_InventoryMovement` và gộp vào công nợ sân nếu có `bookingCode` hợp lệ. |
| **Upload & Quản lý ảnh sản phẩm (`/Admin/Products`)** | `POST /Admin/Products/Create`, `POST /Admin/Products/Edit/{id}` | `ProductsController`, `ProductImageService` (`SixLabors.ImageSharp`) | `tb_Product`, `tb_InventoryMovement` | Kiểm tra magic bytes, MIME, kích thước `<= 5 MB`, giải mã thật, xóa metadata, thu nhỏ `<= 1200px`, lưu `.webp` tại `wwwroot/uploads/products/` và cập nhật `tb_Product.Image`. |
| **Điều phối Sân, POS & Sổ cái (`/Management`)** | `POST /api/admin/bookings/{code}/status`, `POST /api/admin/bookings/{code}/pos-item`, `POST /api/admin/bookings/{code}/payments`, `POST /api/admin/bookings/{code}/refunds` | `BookingService`, `OrderService`, `ApiDbController` | `tb_Booking`, `tb_Product`, `tb_PaymentTransaction`, `tb_InventoryMovement`, `tb_AuditLog` | Tách biệt hoàn toàn việc Kết thúc ca chơi (`status = completed`) với việc Thu tiền (`tb_PaymentTransaction` loại `payment`) và Hoàn tiền (`refund`). Bắt buộc nhập mã tham chiếu khi chuyển khoản (`transfer`). |
| **Báo cáo Doanh thu & Công nợ (`/Reports`)** | `GET /api/admin/reports/ledger` | `ApiDbController.GetLedgerReport` | `tb_PaymentTransaction`, `tb_Booking`, `tb_Order`, `tb_Account` | Tổng hợp doanh thu thực thu ròng (`Thực thu - Hoàn tiền`) trực tiếp từ sổ cái `tb_PaymentTransaction` theo khoảng ngày lọc. |

# Ma Trận Hợp Đồng DOM, Selectors & Sự Kiện JavaScript (`DOM_CONTRACT_MATRIX.md`)

Tài liệu này khóa chặt các `id`, `class`, `data-*` và hàm sự kiện giữa các tệp JavaScript (`shared.js`, `dashboard.js`, `booking.js`, `menu.js`, `lookup.js`, `checkin.js`, `management.js`, `reports.js`) và các Razor Views. **Toàn bộ các selector dưới đây được giữ nguyên 100% trong bản nâng cấp V7.**
